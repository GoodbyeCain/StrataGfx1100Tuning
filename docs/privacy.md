# 公开材料与隐私

发布目录通过白名单重建，不直接复制原运维事件目录或其Git历史。只包含v0.2.2相关补丁、占位符配置、通用运行脚本、人工整理报告、合成提示词和逐请求性能数值。

没有发布真实API密钥、令牌、SSH材料、账户邮箱、个人绝对路径、主机名、局域网地址、内部域名、代理配置、会话标识、进程ID、原始生产配置、配置备份或系统/服务日志。GPU型号、CPU、工具链版本、日期和公开源码/二进制哈希用于解释测量条件；个人机器的PCI地址不保留。

逐请求数据通过明确字段白名单导出，保留tokens、timings、墙钟、完成原因、提示词hash及草稿接受指标，删除生成文本预览。资源数据只保留各组聚合值和Lt上下文汇总，不保留带时间戳的逐进程轨迹。验收只公开合成用例的通过标志与计时，不复制完整原始响应或网络接入记录。

两份公开JSON使用 `@STRATA_ROOT@` 等占位符，默认localhost18080、无密钥。`configure.py`生成真实绝对路径到被Git忽略的 `runtime/`；其本地JSON默认文件权限600。`.local.json`、日志、私钥常用后缀与环境文件也被忽略。忽略规则不能代替人工检查，尤其不要使用 `git add -f` 提交个人runtime。

维护本仓库时，提交前检查新增文件、暂存差异、密钥格式、邮箱和非公开网络/路径；提交作者使用公开GitHub用户名与noreply邮箱。本次检查结果和未验证项记录于[发布验证](publication-validation.md)。
